# Versioned Releases of the Code After Series

This folder contains the versioned releases of the Code After Series. Each version
represents a stable, citable snapshot of the work at a specific point in time.

## Purpose of This Folder
The `/versions` folder provides:

- a clear historical record of the evolution of the Series
- stable references for citation and scholarly use
- separation between working drafts and published releases
- a foundation for multilingual and derivative editions

## Versioning Model
The Series follows a structured versioning approach:

- **0.x** — developmental and pre‑release versions  
- **1.0** — first stable, public release  
- **1.x** — incremental improvements  
- **2.0+** — major conceptual expansions
