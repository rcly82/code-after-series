# Code After — Series Repository

**Code After** is a global, multilingual research programme examining what AI is doing to the societies and institutions we live in.  
This repository hosts the core structure, documentation, and versioned releases of the *Code After Series*.

## Purpose of This Repository
This repository provides the canonical, public-facing structure for the Code After Series, including:

- versioned releases of the text (v0.9 → v1.0 → future volumes)
- documentation and explanatory notes
- metadata and citation files
- multilingual scaffolding for global editions
- links to authoritative archival locations (Zenodo, SSRN, ORCID)

It is **not** a PDF archive.  
All official PDFs are stored in their permanent scholarly homes and linked below.

## Canonical Locations for Published Versions
To avoid version drift and ensure scholarly integrity, all published versions of Code After live in stable archival repositories:

- **Zenodo (Concept DOI):**  
  https://doi.org/10.5281/zenodo.XXXXXXX  
- **SSRN Abstract Page:**  
  https://papers.ssrn.com/sol3/papers.cfm?abstract_id=6681179  
- **ORCID Author Record:**  
  https://orcid.org/0009-0000-7611-6323

GitHub links to these locations but does not duplicate them.
