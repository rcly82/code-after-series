# Metadata for the Code After Series

This folder contains the canonical metadata files for the Code After Series.  
These files ensure long-term stability, discoverability, and archival integrity across
Zenodo, SSRN, ORCID, GitHub, and future publication platforms.

## Files in this folder

### `CITATION.cff`
Standard citation metadata used by GitHub and citation managers.  
Defines authorship, version, DOI references, and citation instructions.

### `zenodo.json`
Metadata used by Zenodo to generate the Concept DOI and versioned release records.

### `series-metadata.yaml`
A human-readable metadata anchor for the entire Code After Series, including:
- canonical links  
- version history  
- licensing  
- multilingual expansion plans  

## Purpose
These files collectively form the metadata spine of the Code After Series, ensuring:
- consistent citation  
- stable archival references  
- clean versioning  
- interoperability across platforms
